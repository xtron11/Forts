# Крепости

Стратегия для Telegram Mini App (Phaser + TypeScript). Описание проекта и принципы — в [claude.md](claude.md).

## Структура

- `client/` — игра: Vite + TypeScript + Phaser 4.
  - `src/platform/` — единственное место, где есть Telegram (TelegramPlatform) и тестовый игрок для браузера (BrowserPlatform).
  - `src/game/` — сцены, изометрия, тема.
  - `src/i18n/` — тексты ru/en.
- `shared/` — общий код клиента и сервера: конфиги зданий, ресурсы, правила размещения.

## Команды

Нужен Node.js 20+.

```bash
npm install        # зависимости для всех пакетов
npm run dev        # игра на http://localhost:5173
npm run build      # проверка типов + сборка в client/dist
npm run typecheck  # только проверка типов во всех пакетах
npm run preview    # раздать собранный client/dist
```

Другой порт: `npm run dev -- --port 3000`.

## Тестовый игрок в браузере

Вне Telegram подставляется тестовый игрок, его можно настроить через URL:

- `?lang=en` / `?lang=ru` — язык (по умолчанию язык браузера);
- `?name=Вася` — имя;
- `?id=42` — id.

Тема берётся из системной настройки (светлая/тёмная).

## Запуск внутри Telegram

1. Запустить `npm run dev` и открыть туннель с HTTPS, например `cloudflared tunnel --url http://localhost:5173` или `ngrok http 5173`.
2. В @BotFather: `/newapp` (или Menu Button у бота) — указать URL туннеля.
3. Открыть мини-приложение в Telegram. Платформа определяется автоматически по параметрам запуска (`#tgWebAppData`).

## Управление

- Перетаскивание пальцем/мышью — двигать карту.
- Щипок двумя пальцами / колесо мыши — масштаб.
- Тап по пустой клетке — поставить выбранное на нижней панели здание.
