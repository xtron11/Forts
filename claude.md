# Крепости — стратегия в Telegram Mini App

Стратегия в духе Clash of Clans: игрок строит крепость, добывает ресурсы
(золото, еда), тренирует войска и атакует базы других игроков/ботов.
Сессия 1–3 минуты, ресурсы копятся офлайн.

## Стек
- Весь код на TypeScript, монорепозиторий на npm workspaces.
- client/ — игра: Vite + Phaser (последняя стабильная версия) + Telegram WebApp SDK.
  Деплоится на Vercel (Root Directory: client).
- server/ — Node.js API + бот на grammY + PostgreSQL. Деплой на VPS. (появится позже)
- shared/ — общий код клиента и сервера: типы, конфиги зданий/войск,
  формулы ресурсов, логика боя.

## Принципы
- Всё ценное (ресурсы, покупки, результат боя) считает и проверяет сервер.
  Клиенту не доверяем.
- Игровые числа (стоимость, время постройки, характеристики) — только в
  конфигах в shared/, не хардкодить в сценах.
- Всё, что связано с Telegram (вход, оплата, приглашения, вибрация), —
  только через платформенный слой client/src/platform/. Игровой код не
  обращается к window.Telegram напрямую. Цель — позже перенести игру
  на Яндекс Игры / веб без переписывания.
- Игра должна запускаться и в обычном браузере (без Telegram) —
  платформенный слой подставляет тестового игрока.
- Mobile-first: портретная ориентация, тач-управление.
- Графика пока — простые фигуры и заглушки.
- Секреты (токен бота и т. п.) только в .env, никогда не коммитить.
- Тексты интерфейса через простую систему локализации (ru, en).
